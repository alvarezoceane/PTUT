# Supervised Project of the M1 BBS (University of Toulouse)
This project was made by the students : **Alvarez Océane, Benita Ibrahim and Nour Saad** supervised by **Alfonso Pérez Escudero** and **Roger Lloret Cabot** members of the IVEP team at the **CBI laboratories (CNRS)**. The project ran from January to May 2026.

The project aims to apply ***Optimal Foraging Theory*** to simple non-visual organisms, using Caenorhabditis elegans as a model. The study focuses on the ***Marginal Value Theorem*** and relies on a large dataset of 1500 videos showing a single worm exploring environments with varying geometries and food densities. The work consisted of preprocessing these trajectories, implementing automated filters in Python to correct tracking errors, and producing a reliable database ready for further analysis.

n this repository, you will find **folders** containing the internship report and the project specifications, as well as all the code and output files (CSV tables, histograms, and graphs) produced throughout the project.
